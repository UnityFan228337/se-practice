# Smart Campus Room Availability

Small React + TypeScript app that evaluates whether a fictional campus room is available.
It checks time bounds, maximum duration, blocked rooms, and overlaps with existing bookings.

## Setup

```text
cd sis-05/project
npm ci
```

## Commands

```text
npm test
npm run lint
npm run build
npm run dev
```

Only fictional room data is used. No credentials or personal data are required.
